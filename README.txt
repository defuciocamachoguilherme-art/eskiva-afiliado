# Eskiva Afiliado — Vercel

Site estático pronto para Vercel. Não usa login, servidor ou banco de dados.

Estrutura:
- index.html
- vercel.json
- assets/background.gif
- assets/logo.png

Deploy:
1. Entre em https://vercel.com/new
2. Escolha importar um repositório Git ou enviar a pasta/arquivo do projeto.
3. Para este site estático, não é necessário build command.
4. Clique em Deploy.

O CTA do site usa o endereço informado no projeto.
